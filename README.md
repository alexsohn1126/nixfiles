# My nixfiles (and neovim files)

How'd you end up here?

Nonetheless, here are my nixfiles.

### Features:
- Dual boot with Windows and Linux
- i3, polybar setup
- kitty, fish, starship terminal
- neovim setup
- spotify with spotx
- all configured with home-manager

### Warnings to my future self/others daring enough to try this config
This config is meant to be used for both my desktop and laptop.

comment desktop.nix or laptop.nix out depending on what you are using right now.

if spotify is not working, check out this guy's config: https://github.com/oskardotglobal/.dotfiles
